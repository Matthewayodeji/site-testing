ABOUT THIS WORKSPACE

DeeTech

A local SOC review organizer for documenting authorization, web review cases, host and API observations, cloud configuration checks, and analyst-entered findings.

  • No target is contacted, crawled, scanned, or connected to.
  • Authorization entries are records, not proof of permission.
  • Workspace data is stored in this browser's local storage.
  • Use Export workspace to back up or transfer your records.
